Apaajalahh Native (experimental) - Windows x64

Source: https://github.com/rfmoscowsind/Whatsapp-Apaajalahh
Upstream: https://github.com/crmne/zapfast (MIT license)
Based on pinned ZapFast v0.19.0 commit 6f3766a38328ad081120c91e95ae68cc7e7a3466.
The separate version applies local branding, readable dark colors, larger
default UI zoom, and a protocol history read-receipt fix with a regression test.

RUN: Extract all files and launch Apaajalahh.exe.
It uses a NEW local account directory (separate from official ZapFast).
Link a TEST phone number again. This version doesn't reuse your old ZapFast
login, settings, or encrypted message archive.

The WhatsApp protocol is unofficial and may violate WhatsApp's terms.
Do not trust this software with your primary account or sensitive data.
The original upstream MIT and third-party notices are included.
Upstream updates should not replace customized code; keep automatic updates
disabled in the custom build.
